## Intent overlaps to watch
- **CarPlay Dublin vs CarPlay Ireland** — kept separate on purpose: Dublin = we come to the car; Ireland = remote, nationwide. They cross-link. If Search Console shows them swapping places for the same query, merge Ireland into Dublin with a 301.
- **Home vs `/bmw-coding-ireland`** — home owns "bmw coding ireland"; the hub is now "across Ireland — every county & model".
- **`/bmw-coding-dublin` vs county pages** — no overlap (Dublin is not a county page).
- **`/bmw-hidden-features` vs `/bmw-coding-list`** — features overview vs full reference list; fine while both stay distinct.

wins: improve that page's intro, FAQ and photos first.
