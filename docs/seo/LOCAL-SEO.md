# Local SEO — Ireland (owner action plan)

Everything here needs your Google / Meta account, so it is listed as owner
actions. The website side is already consistent: mobile service, no premises
published, locality "Dublin, IE" in the schema.

## 1. Google Business Profile (biggest single lever for "bmw coding dublin")
Competitors in the map pack today: Radio King (4.8★, 1,094 reviews), Bimmerwise (Lusk), BMworkshop (Rathcoole).

1. **Create or claim** the profile at business.google.com with the email you use for the business.
2. **Business name:** exactly the brand used on the site — "BMW Coding" (or "BMW Coding IE"). No keywords added to the name (Google suspends for that).
3. **Primary category:** the closest one Google offers for coding and diagnostics — for example *Auto electrical service* or *Car repair and maintenance service*. Google's category list changes, so pick from what it shows; never a dealer or parts-shop category.
4. **Service-area business:** turn **off** "show business address to customers". Enter a real address for verification only (where you operate from); it stays hidden.
5. **Service areas:** Dublin, Kildare, Wicklow, Meath (add Louth only if you confirm you drive there). Up to 20 areas; do not list counties you only serve remotely.
6. **Hours:** match the diary (admin → hours). The site's schema reads the same table.
7. **Phone / website:** the WhatsApp number used on the site; website `https://www.bmwcoding.ie` (with **www**).
8. **Services:** add each with the site's price — CarPlay €150/€220, Japan → EU €250/€280, Diagnostics from €80, ID4 → ID6 €50, Android Auto €200, plus "quoted" items (retrofits, maps, 6WB). Link each to its page (see KEYWORD-STRATEGY.md).
9. **Photos:** only real jobs (the same photos as the gallery/projects page) — screens, clusters, the car on the driveway. 10+ to start, then 1–2 a week. No generated images.
10. **Reviews:** after every paid job send the review link (the bot's `/review` command already has the text). Never offer anything in exchange, never write them yourself. Reply to every review within 48 h — short, by name, mention the job.
11. **Posts:** one per week — a finished job photo + one line + link to the service page.
12. **Q&A:** add the 5 most common questions yourself (CarPlay on my car? remote? call-out fee? payment on completion? Japanese import?).
